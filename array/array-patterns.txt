🧠 ARRAY DSA PATTERNS (MASTER THIS FIRST)
🟢 1. Simple Traversal Pattern
When to use:

Visit each element once

No optimization needed

Key idea:
for i = 0 → n-1

Practice Problems:

Sum of array elements

Find maximum & minimum

Count even and odd numbers

Check if array is sorted

🟢 2. Reverse Traversal Pattern
When to use:

Reverse array

Compare from end

Key idea:
for i = n-1 → 0

Practice Problems:

Reverse an array

Print array in reverse

Reverse array using extra space

🟢 3. Two Pointers Pattern
When to use:

Need to compare from both ends

Array is sorted OR can be sorted

Key idea:
left++, right--

Practice Problems:

Reverse array in-place

Check palindrome array

Pair sum in sorted array

Remove duplicates from sorted array

🟡 4. Sliding Window Pattern
When to use:

Subarray problems

Continuous elements

Types:

Fixed window

Variable window

Practice Problems:

Max sum subarray of size K

Count subarrays of size K

Longest subarray with sum ≤ K

🟡 5. Prefix Sum Pattern
When to use:

Multiple range sum queries

Subarray sum problems

Key idea:
prefix[i] = prefix[i-1] + arr[i]

Practice Problems:

Range sum queries

Subarray sum equals K

Equilibrium index

🟡 6. Sorting-Based Pattern
When to use:

Order helps simplify logic

Key idea:
sort → solve

Practice Problems:

Second largest element

Majority element (basic)

Merge two sorted arrays

Find missing number

🟠 7. Binary Search Pattern
When to use:

Sorted array

Search space reduction

Key idea:
low ≤ high → mid

Practice Problems:

Binary search

First & last occurrence

Find floor & ceil

Search insert position

🟠 8. Frequency Array / Hashing Pattern
When to use:

Counting occurrences

Range limited values

Key idea:
freq[arr[i]]++

Practice Problems:

Count frequency of elements

Find duplicate number

Find first non-repeating element

Intersection of two arrays

🔵 9. Kadane’s Algorithm Pattern
When to use:

Maximum subarray sum

Key idea:
currentSum = max(arr[i], currentSum + arr[i])

Practice Problems:

Maximum subarray sum

Maximum sum circular array (later)

🔵 10. Cyclic Sort Pattern
When to use:

Numbers from 1 → N

Missing / duplicate problems

Key idea:
place number at correct index

Practice Problems:

Missing number

Find duplicate

Find all missing numbers

🎯 ARRAY PATTERN LEARNING ORDER (IMPORTANT)

1️⃣ Simple traversal
2️⃣ Two pointers
3️⃣ Sliding window
4️⃣ Prefix sum
5️⃣ Sorting
6️⃣ Binary search
7️⃣ Kadane
8️⃣ Cyclic sort

⏳ Suggested Plan

Dry run every problem
